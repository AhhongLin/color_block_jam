# 09 — 同色門離場、過關判定與重設關卡

**What to build:** 方塊滑到邊界時，若前緣完全對齊同色門就整個滑出盤面消失；盤面上所有方塊都離場時觸發過關；玩家可以隨時按「重設關卡」把方塊還原到關卡初始位置重來。這張票讓 08 做出來的滑動機制變成一個真正「可以玩完」的單一關卡。

**Blocked by:** 08 — 方塊拖曳滑動與碰撞邏輯

- [ ] 方塊滑到邊界時，檢查其前緣所有格子是否都對齊同色門；完全對齊才整個滑出盤面並移除，只要有一格沒對齊就視同撞牆停下
- [ ] 盤面上所有方塊都離場時，判定為過關，顯示過關狀態/畫面
- [ ] 提供「重設關卡」按鈕，點擊後所有方塊回到該關卡初始的 `blocks` 資料狀態
- [ ] 離場、過關、重設判定的核心邏輯依 spec.md 第 8 節用 TDD 開發，涵蓋「部分對齊不可離場」「多門同色皆可離場」等案例
- [ ] 此階段不需要處理死局偵測（spec.md 明確排除）
