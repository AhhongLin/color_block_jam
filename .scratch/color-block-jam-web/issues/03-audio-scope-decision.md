# 音效範圍決策

Type: grilling
Status: resolved

## Question

MVP 要不要包含音效/背景音樂？如果要，範圍多大（僅互動音效、或含背景音樂）？決定後記錄採用的素材來源，或明確記為之後擴充項目。

## Answer

1. **範圍**：MVP 只做互動音效，不做背景音樂（背景音樂需要選曲/循環播放/靜音開關等額外設計，留給之後擴充）。
2. **觸發時機**：僅「方塊離場（滑出同色門）」與「過關完成」這兩個時機播放音效；方塊滑動/停下、UI 操作（選單點擊等）不做音效。
3. **素材來源**：從免費音效庫（如 freesound.org）挑選 CC 授權的短音效，實作時下載放進 assets 資料夾，需標註授權條款。

## 實作階段更新（ticket 12）

ticket 12 把觸發時機擴大為「離場」「過關」「方塊移動」「UI 操作（選單點擊等）」四項，跟本文件第 2 點原本的排除範圍矛盾。實作階段依 ticket 12 為準，四項都做；spec.md 5 節已同步更新。
