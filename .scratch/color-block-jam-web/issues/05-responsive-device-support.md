# 響應式與裝置支援範圍

Type: grilling
Status: resolved

## Question

網頁版要支援到什麼裝置範圍？僅桌面滑鼠點擊，還是要支援觸控/行動裝置？版面需不需要響應式（RWD）設計？

## Answer

1. **裝置範圍**：桌面 + 行動裝置都要支援，滑鼠拖曳與觸控拖曳並存（用瀏覽器 Pointer Events 統一處理）。
2. **輸入方式**：只支援拖曳操作，不做「點選方塊 + 方向鍵」這種替代輸入。
3. **響應式設計**：需要 RWD，從手機直向到桌面寬螢幕都要適配，盤面格子尺寸依螢幕寬度等比例縮放，關卡選單與其他 UI 元素也要在不同寬度下保持可用。
