# 08 — 方塊拖曳滑動與碰撞邏輯

**What to build:** 玩家可以用滑鼠或觸控拖曳方塊，方塊依拖曳方向滑動，遇到牆壁或其他方塊會正確停下（只停不推），支援任意多格拼接形狀的碰撞判定。玩家可以在畫面上實際拖動 07 渲染出來的方塊並看到正確的滑動結果。

**Blocked by:** 07 — 專案骨架、路由與靜態盤面渲染

- [ ] 透過 Pointer Events 統一處理滑鼠拖曳與觸控拖曳，判斷出上/下/左/右其中一個滑動方向
- [ ] 滑動判定採逐格模擬：整個方塊形狀每次往指定方向移動一格，檢查所有新格子是否都在盤面內且未被佔用
- [ ] 撞到盤面邊界（非門格）或其他方塊時，停在最後一個可行位置，不推動對方
- [ ] 拖曳過程中方塊即時跟著滑鼠/手指移動（不必等放開才動）；放開時停在放開當下最接近的那一格，可行範圍仍受碰撞限制（不會被拖過障礙物）。方塊移動用 CSS transition（`transform`）呈現平滑動畫
- [ ] 核心滑動/碰撞邏輯（純函式，不含 UI）依 spec.md 第 8 節用 TDD 開發，涵蓋單格方塊、多格方塊、L 形方塊的碰撞案例
- [ ] 此階段方塊滑到門邊界時先不處理離場（那是 09 的範圍），停在邊界前即可

**Status:** ready-for-agent

## Comments

- 實作過程中調整需求：原本「拖曳只決定方向，放開後自動滑到底」改成「拖曳中即時跟手，放開時停在放開當下的格子（鉗制在碰撞可行範圍內）」。已同步更新 spec.md 2.2 節。
