# 核心滑動與碰撞規則精確化

Type: grilling
Status: claimed

## Question

明確定義方塊滑動與碰撞的完整規則，寫入規格文件的核心機制章節，需要涵蓋：

- 方塊滑動的觸發方式：點擊/點選方塊後往哪個方向滑？如果有多個可行方向，怎麼決定（自動挑選唯一可行方向，還是需要玩家額外指定方向）？
- 撞到無門的邊界格、撞到其他方塊時的停止規則。
- 多格方塊（L 形、2x1 等）滑動時的碰撞判定——用哪一格代表方塊前緣？整個方塊形狀怎麼跟盤面上其他佔用格子做碰撞檢查？
- 到達邊界門格時：門的顏色是否要跟整個方塊完全對齊才能離開？如果方塊只有一部分格子對到門，能不能出去？
- 方塊之間是否會互相卡死導致死局？MVP 要不要偵測「無解」狀態並提示玩家？
