# 核心滑動與碰撞規則精確化

Type: grilling
Status: resolved

## Question

明確定義方塊滑動與碰撞的完整規則，寫入規格文件的核心機制章節，需要涵蓋：

- 方塊滑動的觸發方式：點擊/點選方塊後往哪個方向滑？如果有多個可行方向，怎麼決定（自動挑選唯一可行方向，還是需要玩家額外指定方向）？
- 撞到無門的邊界格、撞到其他方塊時的停止規則。
- 多格方塊（L 形、2x1 等）滑動時的碰撞判定——用哪一格代表方塊前緣？整個方塊形狀怎麼跟盤面上其他佔用格子做碰撞檢查？
- 到達邊界門格時：門的顏色是否要跟整個方塊完全對齊才能離開？如果方塊只有一部分格子對到門，能不能出去？
- 方塊之間是否會互相卡死導致死局？MVP 要不要偵測「無解」狀態並提示玩家？

## Answer

1. **觸發方式**：玩家在方塊上拖曳/滑動手勢指定方向（上下左右四方向之一），方塊沿該方向開始滑動。
2. **碰撞（撞方塊）**：只停不推——撞到其他方塊就停在緊鄰的前一格，不會推動對方。
3. **多格方塊碰撞判定**：逐格模擬——整個形狀（含 L 形等）每次往指定方向整體移一格，檢查新位置所有格子是否都在盤面內且未被佔用，可行就繼續、不行就停在上一步。
4. **離場對齊**：方塊滑到邊界門時，需要方塊前緣的所有格子都對齊同色門格，才會整個滑出盤面消失；只要有一格沒對齊同色門，就停在邊界前面（視同撞牆）。
5. **死局處理**：MVP 不做死局偵測，改為提供「重設關卡」按鈕讓玩家自行重來。
