# 關卡數量與難度曲線設計

Type: grilling
Status: resolved

## Question

MVP 要手工設計幾關範例關卡？難度曲線怎麼安排（例如：前幾關教學、之後漸進提升難度）？需要等「核心滑動與碰撞規則精確化」定案後才能具體設計關卡內容。

## Answer

1. **關卡數量**：MVP 手工設計 8 關。
2. **難度曲線**：線性遞進——第 1-2 關單一機制純教學（少量 1x1/2x1 方塊、規則矩形盤面）；第 3-5 關開始加入 L 形方塊、不規則盤面；第 6-8 關方塊數量與盤面複雜度拉高，需要多步規劃。
3. **新手引導**：不做額外的教學提示 UI，靠關卡設計本身教會玩家（例如第 1 關就是最簡單的單一方塊 + 單一門）。
